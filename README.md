## 📖 Project Overview

**FreelanceFinder** explores the end-to-end software development lifecycle (SDLC) for a two-sided freelance talent portal:
- **Client Workflow**: Job posting, proposal review, escrow milestone tracking, and freelancer ratings.
- **Freelancer Workflow**: Profile portfolio showcasing, proposal bidding, milestone deliverables, and earnings management.

## 🛠️ Target Technology Architecture

- **Frontend**: React.js, Tailwind CSS / Bootstrap, React Router, Axios
- **Backend**: Node.js, Express.js REST API
- **Database**: MongoDB (Mongoose ODM) with cloud Atlas clustering
- **Authentication**: JWT (JSON Web Tokens) with role guards (Client vs Freelancer)
